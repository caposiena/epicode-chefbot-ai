# Modello addestrato

Il file del modello non viene salvato subito nella repository perché deve essere generato dal notebook con un addestramento reale.

Al termine del training, il modello viene esportato in questa cartella con il nome:

```text
chefbot_mobilenet.keras
```

Il file `class_names.json` contiene invece l'ordine delle classi utilizzato durante l'addestramento e dall'applicazione.
